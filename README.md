# Kodanzcamp

Build the Zillow for summer camps. Homepage should have basic form: zipcode, age of child and interests. Show a list of summer camps sorted by distance and cost. Allow list and map views. Put a calendar icon to save to calendar, and show users the ability to select for partial weeks or full summer. Homepage should tell new users what's on the site. Build similar to attachment.
